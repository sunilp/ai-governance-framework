# DE-007 evidence: Machine-readable marking of generated output

Placeholder in the example evidence pack for the [governance gate](../../../reference-implementations/README.md). In a real pack this file is the record itself, or a pointer to it in the records system with its document ID, version and SHA-256.

- **Record:** Marking design and detection test results, or the exception relied on, per jurisdiction.
- **Where in this example:** [transparency standards](../../../framework/responsible-ai/transparency-standards.md)
- **Gap in this example:** The example does not address marking of generated text. A real pack records the rule applied or the exception relied on, with the legal basis.
- **Control:** DE-007 in the [control register](../../../framework/governance-operations/control-register.md)
